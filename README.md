# home-security
A Raspberry Pi-based motion-triggered security system with email alerts. Please see the report pdf for an in-depth review.
![Project Report.pdf](https://github.com/YanLUsername/home-security/blob/main/Project%20Report.pdf)

### Finished Build
![Finished Build](https://github.com/user-attachments/assets/45fd28e2-713e-47cd-a03e-aed47eca6e05)

### Features
- Motion detection
- Email notifications
- Light detection
- Temperature measuring
- LCD output
- Buttons for system control

### Hardware
- Raspberry Pi 5 w/ GPIO Extension Board
- ADC Module
- LCD
- Ultrasonic Sensor
- Photoresistor
- Thermistor
- LEDs
- Buttons
- Resistors, Jumper Wires, Breadboard
